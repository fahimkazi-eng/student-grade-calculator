# 📊 Student Grade Calculator

A simple web-based grade calculator built as a beginner web development project.

## ✨ Features

- Enter marks for three subjects
- Calculate total marks
- Calculate average marks
- Automatically determine the grade
- Input validation
- Simple and responsive interface

## 🛠️ Technologies

- HTML
- CSS
- JavaScript

## 🎯 Purpose

This project was created to practice fundamental web development concepts, including HTML structure, CSS styling, JavaScript functions, variables, conditions, and DOM manipulation.

## 🚀 Future Improvements

- Add more subjects
- Add GPA calculation
- Add student name and subject names
- Improve the user interface
- Add dark mode
